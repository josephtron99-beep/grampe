Grampe · Design system

Design system

Tokens and components shared by every Grampe page. Styles live in assets/css/tokens.css and assets/css/components.css. Page files (like home.css) only arrange these parts.

Rules

  • Use semantic colour tokens (--color-primary, --color-text-muted…). No hex values in components or page CSS.
  • Font sizes come from the type scale (--fs-*). Headings use .display, .h2, .h3, .title.
  • Spacing uses the 4px scale (--space-*) and the rhythm tokens: --section-gap, --group-gap, --block-gap, --grid-gap, --card-pad, --tile-pad.
  • Corners use --radius-*. Large surfaces = .card (xl), small surfaces = .tile (md), buttons = sm, badges and chips = pill.
  • Every section starts with a section head: .eyebrow → heading → .sub.
  • Badge = status label (not clickable). Chip = clickable pill. Button = main action.
