# Product Manager (Grampe)

## Homepage goals
1. Sign-ups (Create Account) - primary metric.
2. Explain GINR clearly - secondary.
3. Build trust (security, transparency via gccscan, safety notices).

## Scope rules
- Reuse existing content/sections; change design, not the offer.
- Static and fast; deployable to Vercel as plain files from GitHub.
- Demo balances are labelled as illustrative, never presented as real data.

## Acceptance criteria
- Existing links preserved: services.html#bills/#pay/#travel/#card/#wealth, ginr.html, airdrop.html, download.html, Signin.html, signup.html, forgot-password.html, Telegram, gccscan.
- Works at 375 / 768 / 1280 / 1440 widths.
- No console errors; keyboard navigable.
- Footer has risk disclaimer; flag missing Privacy / Terms pages.
